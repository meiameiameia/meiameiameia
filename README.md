# hey, I'm Matheus 👋

This is the side of my GitHub where **“I wonder if I could make that”** tends to get out of hand.

There's a lot of Stardew Valley here.

I like making mods and tools that feel like they could naturally belong around the game rather than fighting against it — fixing little annoyances, adding systems I wish existed, or making modding itself nicer to deal with.

That has somehow led me from small tweaks to things like desktop tools, larger gameplay systems, mod maintenance, and a growing collection of ideas that were definitely supposed to stay small.

Outside Stardew, I also occasionally disappear into Windows utilities, controllers, Linux experiments, or whatever technical rabbit hole seems interesting that week.

I don't really have a strict theme for this account beyond:

> **if it sounds fun to build, it probably belongs here.**

Some projects become polished enough that other people use them.

Some stay experiments.

Some exist mostly because I learned something while making them.

I like all three.
